# Raven Observability Rollout: design summary

Raven Observability Rollout ran from 2024-06 to 2024-08.
The Raven Observability Rollout stack is built on SQL, Django, Solidity and Flask.
Raven Observability Rollout uses SQL for the public interface.
Raven Observability Rollout uses Django for its core services.
Raven Observability Rollout uses Solidity for the public interface.
Raven Observability Rollout uses Flask for data movement.
