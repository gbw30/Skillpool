# Tundra Enterprise Pilot: program brief

Tundra Enterprise Pilot is a Sales and Partnerships project at Larkfield. It ran from 2025-04 to 2025-11.
Tundra Enterprise Pilot relies on Account Planning, Negotiation, Salesforce and Gong.
Tundra Enterprise Pilot uses Account Planning for day-to-day tracking.
Tundra Enterprise Pilot uses Negotiation for the final deliverables.
Tundra Enterprise Pilot uses Salesforce for the final deliverables.
Tundra Enterprise Pilot uses Gong for reporting.
