# Delta Chat Support Launch: project brief

Delta Chat Support Launch is a Customer Support project at Larkfield. It ran from 2025-03 to 2025-07.
Delta Chat Support Launch relies on Jira, SQL, Zendesk, Technical Writing and Customer Onboarding.
Delta Chat Support Launch uses Jira for reporting.
Delta Chat Support Launch uses SQL for handoffs between teams.
Delta Chat Support Launch uses Zendesk for handoffs between teams.
Delta Chat Support Launch uses Technical Writing for the main workflow.
Delta Chat Support Launch uses Customer Onboarding for handoffs between teams.
