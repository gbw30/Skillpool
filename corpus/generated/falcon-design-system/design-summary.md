# Falcon Design System: design summary

Falcon Design System is a Web and Mobile project at Larkfield. It ran from 2025-04 to 2025-12.
Falcon Design System relies on Vue, GraphQL and CSS.
Falcon Design System uses Vue for its core services.
Falcon Design System uses GraphQL for the public interface.
Falcon Design System uses CSS for monitoring.
The team is listed in the kickoff email for this project.
