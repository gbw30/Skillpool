# Harbor Reporting Pipeline: design summary

Harbor Reporting Pipeline is a Data and Analytics project at Larkfield. It ran from 2023-02 to 2023-11.
Harbor Reporting Pipeline relies on BigQuery, Python, SQL, Tableau, Excel and Airflow.
Harbor Reporting Pipeline uses BigQuery for data movement.
Harbor Reporting Pipeline uses Python for the public interface.
Harbor Reporting Pipeline uses SQL for monitoring.
Harbor Reporting Pipeline uses Tableau for deployment.
Harbor Reporting Pipeline uses Excel for data movement.
Harbor Reporting Pipeline uses Airflow for deployment.
