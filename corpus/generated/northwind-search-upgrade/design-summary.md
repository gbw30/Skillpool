# Northwind Search Upgrade: design summary

Northwind Search Upgrade ran from 2023-04 to 2023-07.
The Northwind Search Upgrade stack is built on Google Cloud, Django, Solidity and C#.
Northwind Search Upgrade uses Google Cloud for monitoring.
Northwind Search Upgrade uses Django for monitoring.
Northwind Search Upgrade uses Solidity for its core services.
Northwind Search Upgrade uses C# for the public interface.
