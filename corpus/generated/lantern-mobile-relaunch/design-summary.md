# Lantern Mobile Relaunch: design summary

Lantern Mobile Relaunch ran from 2024-06 to 2024-07.
The Lantern Mobile Relaunch stack is built on React Native, Vue, C#, C++ and NoSQL.
Lantern Mobile Relaunch uses React Native for data movement.
Lantern Mobile Relaunch uses Vue for the public interface.
Lantern Mobile Relaunch uses C# for its core services.
Lantern Mobile Relaunch uses C++ for deployment.
Lantern Mobile Relaunch uses NoSQL for data movement.
