# Zephyr Partner API: design summary

Zephyr Partner API ran from 2023-06 to 2023-07.
The Zephyr Partner API stack is built on MongoDB, Python, Flask, Swift and C++.
Zephyr Partner API uses MongoDB for the public interface.
Zephyr Partner API uses Python for deployment.
Zephyr Partner API uses Flask for deployment.
Zephyr Partner API uses Swift for data movement.
Zephyr Partner API uses C++ for its core services.
