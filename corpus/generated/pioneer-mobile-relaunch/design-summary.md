# Pioneer Mobile Relaunch: design summary

Pioneer Mobile Relaunch ran from 2024-01 to 2024-11.
The Pioneer Mobile Relaunch stack is built on Vue, Solidity and React Native.
Pioneer Mobile Relaunch uses Vue for monitoring.
Pioneer Mobile Relaunch uses Solidity for its core services.
Pioneer Mobile Relaunch uses React Native for the public interface.
