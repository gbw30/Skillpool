# Borealis Partner API: design summary

Borealis Partner API ran from 2025-02 to 2025-08.
The Borealis Partner API stack is built on AWS, Azure, Django, Flask and Snowflake.
Borealis Partner API uses AWS for monitoring.
Borealis Partner API uses Azure for the public interface.
Borealis Partner API uses Django for data movement.
Borealis Partner API uses Flask for deployment.
Borealis Partner API uses Snowflake for deployment.
