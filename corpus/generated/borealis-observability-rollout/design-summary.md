# Borealis Observability Rollout: design summary

Borealis Observability Rollout is a Platform Engineering project at Larkfield. It ran from 2025-03 to 2025-09.
Borealis Observability Rollout relies on Redis, Go, Kubernetes, Docker and Terraform.
Borealis Observability Rollout uses Redis for monitoring.
Borealis Observability Rollout uses Go for deployment.
Borealis Observability Rollout uses Kubernetes for deployment.
Borealis Observability Rollout uses Docker for data movement.
Borealis Observability Rollout uses Terraform for data movement.
