# Helix Partner API: design summary

Helix Partner API ran from 2023-05 to 2023-12.
The Helix Partner API stack is built on Solidity, Django and MySQL.
Helix Partner API uses Solidity for data movement.
Helix Partner API uses Django for the public interface.
Helix Partner API uses MySQL for its core services.
The team is listed in the staffing note for this project.
