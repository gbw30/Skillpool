# Vertex Observability Rollout: design summary

Vertex Observability Rollout ran from 2023-06 to 2023-08.
The Vertex Observability Rollout stack is built on Angular, JS, Node.js and Spring.
Vertex Observability Rollout uses Angular for the public interface.
Vertex Observability Rollout uses JS for data movement.
Vertex Observability Rollout uses Node.js for monitoring.
Vertex Observability Rollout uses Spring for deployment.
The team is listed in the staffing note for this project.
